settings_ui_enabled()

class-plugin.php : 259

Determines whether the settings admin UI should be registered.

public static settings_ui_enabled() : bool

Deployments that need to lock configuration down can define the PEDALCMS_DISABLE_SETTINGS_UI constant as true, or filter the return value, to remove the settings page and the links pointing at it.

Only the UI is affected. The settings system itself is untouched: stored values are still read by Plugin::get_option() and can still be written programmatically, so a site can be configured first and locked down afterwards.

Tags
since
0.6.4
Return values
bool —

True when the settings UI should be registered.
