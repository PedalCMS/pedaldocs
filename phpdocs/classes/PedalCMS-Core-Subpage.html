$aria_label

class-subpage.php : 73

The label to use for the aria-label attribute in program subnavigation.

public string $aria_label = ''

Allows subpage to be contextualized in the case where menu items may be duplicates of other navigation items. For example, news may also appear in main navigation and we use this property to make it explicit that news in the subnav is specific to the current program.
