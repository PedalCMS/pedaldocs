relabel_archive_crumb()

breadcrumbs.php : 122

Applies our `breadcrumb_label` to the archive crumb of an existing trail.

relabel_archive_crumb(array<string|int, mixed> $crumbs, string|int $text_key) : array<string|int, mixed>

Third-party generators build the archive crumb from post_type_archive_title(), so the crumb still carrying that exact text is the one to relabel. Matching on the text rather than on position means a trail that hides the current item, or orders its crumbs differently, is left untouched instead of having some other crumb rewritten.

Parameters
$crumbs : array<string|int, mixed>

The current trail of crumbs.

$text_key : string|int

The key holding the crumb text for this generator.

Tags
since
0.6.4
Return values
array<string|int, mixed> —

The filtered trail of crumbs.
