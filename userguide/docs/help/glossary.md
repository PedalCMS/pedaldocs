# Glossary

A good course comes with a vocabulary list. Here are the terms used across the lessons, in alphabetical order, with the lesson where each one matters most.

Archive
:   A page that lists a group of items. `/programs/` is the archive of programs, and `/college/college-of-health-sciences/` is the archive of programs, courses and people in one college. See [Lesson 6](../programs/program-finder.md) and [Lesson 9](../organizing/taxonomies.md).

Block
:   A building piece of the WordPress editor, such as a paragraph or an image. Pedal CMS adds three of its own. See [Lesson 11](../extras/blocks.md).

Block theme
:   A WordPress theme that builds its pages from block templates, which you edit in the Site Editor. Pedal CMS registers its own templates for these themes. See [Lesson 11](../extras/blocks.md).

Breadcrumbs
:   The trail of links, such as *Home > Programs > Nursing (ADN)*, that shows where a visitor is. Pedal CMS relies on a supported breadcrumb plugin to draw them. See [Lesson 3](../getting-started/look-and-feel.md).

Classic theme
:   A traditional WordPress theme whose pages come from PHP template files rather than block templates.

College
:   A grouping for programs, courses and people, such as *College of Health Sciences*. You can rename it, for example to "School". See [Lesson 9](../organizing/taxonomies.md).

Course
:   One class in the course catalog, with a code, credits and instructors. See [Lesson 7](../courses/course-catalog.md).

Course Catalog
:   The collection of all your courses, found at `/courses/`. It can be switched off. See [Lesson 7](../courses/course-catalog.md).

Department
:   A grouping for programs, courses and people that can be tied to a college by the **Depends on College** setting. See [Lesson 9](../organizing/taxonomies.md).

Directory
:   The faculty and staff listing at `/directory/`. See [Lesson 8](../directory/faculty-staff.md).

Enable Archive
:   A taxonomy setting. When on, each term has its own page; when off, links to the term lead to a filtered list. See [Lesson 9](../organizing/taxonomies.md).

FAQ
:   A question and answer. A global FAQ is written once and reused on many programs; a local FAQ is written on one program only. See [Lesson 10](../organizing/faqs.md).

Ghost
:   The Presentation Mode that loads no Pedal CMS styling. See [Lesson 3](../getting-started/look-and-feel.md).

Instruction Mode
:   A grouping that says how a program is taught, such as *In-person*, *Online* or *Hybrid*. See [Lesson 9](../organizing/taxonomies.md).

Permalink
:   The permanent web address of a page. **Settings > Permalinks** controls the structure, and saving it refreshes WordPress's list of addresses. See [Lesson 1](../getting-started/installing.md).

Personnel Category
:   A grouping for people, such as *Faculty* or *Staff*. See [Lesson 8](../directory/faculty-staff.md).

Presentation Mode
:   The setting that decides how much styling Pedal CMS applies: **Ghost** (none), **Stealth** (basic) or **Tuxedo** (full). See [Lesson 3](../getting-started/look-and-feel.md).

Program
:   A course of study that you market, such as *Nursing (ADN)*. It is the central content type of Pedal CMS. See [Lesson 4](../programs/first-program.md).

Program Finder
:   The searchable list of programs at `/programs/`. See [Lesson 6](../programs/program-finder.md).

Program GUID
:   A unique code you give a program so it can be matched to other systems, such as an application system. It can be used in button address patterns. See [Lesson 4](../programs/first-program.md).

Program Type
:   A grouping for programs, such as *Certificate* or *Associate Degree*. See [Lesson 9](../organizing/taxonomies.md).

Session
:   A grouping for courses that says when they run, such as *Fall* or *Spring*. Many institutions call this a term. See [Lesson 7](../courses/course-catalog.md).

Shortcode
:   A short instruction in square brackets, such as `[pedalcms_terms_grid tax="pedalcms_college"]`, that WordPress replaces with content when the page loads. See [Lesson 12](../extras/terms-grid-shortcode.md).

Slug
:   The last part of an item's web address, built from its title. The slug of "Nursing (ADN)" is `nursing-adn`. See [Lesson 1](../getting-started/installing.md).

Stealth
:   The Presentation Mode with only basic layout styling, designed to blend in with your theme. See [Lesson 3](../getting-started/look-and-feel.md).

Subject
:   A grouping for courses that names the discipline, such as *Nursing*. See [Lesson 7](../courses/course-catalog.md).

Subpage
:   One of the tabs on a program page, such as **Curriculum** or **Cost**, each with its own web address. See [Lesson 5](../programs/subpages.md).

Taxonomy
:   A set of labels used to group content, like colored tabs on folders. Colleges, departments and program types are all taxonomies. See [Lesson 9](../organizing/taxonomies.md).

Term
:   One label inside a taxonomy, such as the college *College of Health Sciences*. Some institutions also use "term" to mean a session; context makes the meaning clear. See [Lesson 9](../organizing/taxonomies.md).

Tuxedo
:   The default Presentation Mode, with a refined, opinionated look. It is the only mode that shows header background images. See [Lesson 3](../getting-started/look-and-feel.md).
